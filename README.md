# 科學社團專案管理範本站

2026/8/19 花蓮「115 學年度國中小科學社團扶助計畫」教師研習的配套教材網。

給參與的國中小老師**會後自學**用：把「經營一個科學社團」拆成幾關，
每一關教老師用兩個 AI 工具（Codex 負責規劃與檢查、Antigravity 負責實作）
做出一樣基金會成果報告書真正需要的東西。

- **純靜態**：每頁一個 `.html`，共用一支 `style.css` 與 `app.js`
- **零外部資源**：不引用任何 CDN、外部字型、外部圖片，整包下載可離線看
- **投影模式**：現場直接投影這個網站上課，不另做簡報

## 頁面

| 檔案 | 內容 |
|---|---|
| `index.html` | 總覽 |
| `install.html` | 行前安裝（八項，可勾選） |
| `method.html` | 兩個 AI 怎麼分工、AI 會編內容的實測案例 |
| `demo.html` | 三個可操作的示範 |
| `needs.html` | 老師的實際痛點對照到哪一關 |

| `github.html` | 關 6：把做好的東西變成一個網址 |
| `refs.html` | 延伸閱讀（每條網址都實際驗過） |
| `workshop.html` | 8/19 場次資訊 |
| `console.html` | 示範用的研習管理台（單檔、14 筆虛構名單） |
