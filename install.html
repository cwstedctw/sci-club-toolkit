01 ChatGPT 帳號

ChatGPT 桌面版與網頁版都要先有帳號才能用。可以用 Google 帳號登入，不必另設一組密碼。免費方案就夠，不必升級付費。

  1. 到 chatgpt.com 註冊或登入（有帳號就跳過）
  2. 登入時可選「繼續使用 Google」，建議用下一項的個人 Gmail，之後 Antigravity 也用同一組
  3. 用瀏覽器登入一次，確認進得去、看得到自己的名字
怎麼算裝好：瀏覽器打得開 chatgpt.com，而且看得到自己的名字。

02 個人 Gmail（@gmail.com）

Antigravity 要用它登入。這是整份清單裡最常出問題的一項。

不要用學校配的 Google 帳號（那種 @xxx.edu.tw 的）。 官方說明寫得很清楚：機構帳號常常登不進去。沒有個人 Gmail 就先申請一個，免費、三分鐘。
  • 年齡要滿 18 歲並通過驗證，這是 Google 的規定
怎麼算裝好：你手上有一個 @gmail.com 結尾的帳號，而且記得密碼。

agy 讓 Codex 叫得動 agy

上半場你只跟 Codex 講話，它自己在終端機呼叫 agy 去做檔案。 沒有這條指令，Codex 只能停下來請你複製貼上。

裝法：讓剛裝好的 Codex 幫你裝。 你不用自己打安裝指令。把下面這段貼給 Codex，它會去官方頁確認、再幫你跑。
貼給 Codex
我的電腦是 ⟨Windows 或 Mac⟩。
請幫我安裝官方的 Antigravity CLI，裝完終端機要打得動 agy 這個指令。

規則：
1. 只准用官網。安裝說明在 antigravity.google/docs/cli/install，下載頁在 antigravity.google/download。網址開頭不是 antigravity.google 就停下來問我。
2. 裝在我的使用者資料夾，不要要系統管理員權限。
3. 若要跑安裝指令，先把完整指令秀給我看，等我同意再跑。
4. 裝完請新開一個終端機，跑 agy --version，把完整輸出貼給我。不要自己編版本號。
5. 若要我去瀏覽器登入或按允許，一步一步講，等我做好再繼續。
不要貼論壇、影片、聊天室裡別人給的安裝指令。 那種長得像 irm 某個網址 | iex 的句子，只有網址開頭是 antigravity.google 才能跑。
裝完請關掉 ChatGPT 桌面版再重開一次。 新裝的指令有時要重開，Codex 才找得到 agy。 重開後再貼一句：「請跑 agy --version，把完整輸出給我。」
怎麼算裝好：Codex 跑 agy --version 後，回你一串真實的版本號，不是「我找不到這個指令」。

這一項跟前面的 GitHub CLI 不是同一個東西。GitHub CLI 的指令是 gh；這裡要的是 agy。

為什麼 Codex 叫得動 agy 之後，對方知道要做什麼？ 因為它們讀的是同一個資料夾裡的規格與記憶檔。這套教法的完整版在《打造你的 AI 雙人小隊》（教材包 ai-agent-team-course）。8/19 上半場就是：你只跟 Codex 講，它去叫 agy。

05 Antigravity 裝好之後，要調的設定

先認得兩個安全設定。初學者不必為了省幾次確認就放寬整台電腦的權限； 8/19 建議保留 Default，並把產出審核設成 Always Ask。

設定在哪裡：視窗左下角的 Settings（齒輪圖示）， 或直接按 Ctrl + ,（逗號）。

點進去之後選左邊的 General，往下找 Agent Settings：

要改的第一個：Security Preset（安全等級）

Default
🌟 初學者建議保留		 官方寫：工作資料夾以外的檔案存取、以及所有終端機指令，都要人工審核。
→ 會多幾次確認，但能把權限限制在你指定的工作範圍，適合第一次使用。
Full machine AI 可以讀寫這台電腦上的任何檔案。終端機指令雖仍可能要求審核，不代表每一次檔案讀寫都會先問你。
→ 這堂課不需要整台電腦權限，初學者不要選。
Turbo mode 官方寫：關閉所有安全屏障，換取最快的速度。
→ 不要選。你會不知道它對你的電腦做了什麼。
Custom 自己一項一項設。新手用不到。

要改的第二個：Artifact Review Policy（產出審核）

Always Ask
🌟 建議選這個		 它在提出「工作計畫」「修改對照」這類文件時，會先停下來讓你看過再繼續。
→ 多一個看得到它在想什麼的機會。
⚠️ 但這不等於「每個檔案寫進去之前都會問你」——它管的是那些給你看的說明文件， 不是所有的檔案動作。真正的把關還是你自己看成品。
Always Proceed 做完就繼續，不等你看。熟了之後再換。
一個小陷阱：下拉選單按 Esc 關不掉。 我們自己測的時候就是這樣誤選到別的選項。 要取消的話，把選單捲到原本那一項再點一次，或點選單以外的空白處，不要按 Esc 就走。
為什麼要管這個：Antigravity 會讀寫檔案，也可能執行電腦指令。 這堂課用 Default 就夠；看到確認視窗時先讀內容，再決定是否允許。

上面的截圖與英文原文是 2026/8/12 在我們自己的 Windows 機器上拍的（Antigravity 桌面版）。 這兩個選項的完整說明，奕鈞老師整理得非常詳細，想看每個選單逐項對照可以看他的 Google Antigravity 系統設定全攻略。 如果你打開看到的跟這裡不一樣，以你畫面上的為準，並跟我們說一聲，這頁會更新。

06 GitHub 帳號

GitHub 不只是拿來部署網站。它是專案的接力站：保留每次修改的版本，也讓另一台電腦取回同一個 repo。repo 裡的專案記憶、規格與作品會一起帶過去。

  1. 到 github.com 註冊，免費
  2. 用 02 的個人 Gmail 註冊，跟 Antigravity 同一個比較好記
  3. 信箱會收到一封驗證信，點一下就完成
怎麼算裝好：瀏覽器登入 github.com，右上角看得到自己的頭像。

07 Git ＋ GitHub CLI（會後留下版本才用；GitHub Desktop 選配）

Git 負責版本紀錄；GitHub CLI 讓 AI 登入並操作 GitHub。早上現場不必有這兩樣，也能做完課程規劃表。會後要留版本、換電腦接著做，再裝也來得及。有最好。GitHub Desktop 是有畫面的選配。

Windows 到 git-scm.com 下載，安裝時一路按 Next 就好，那些選項不用看懂。
如果出現管理員權限提示，請在自己的筆電確認後再允許；學校配發且被鎖定的電腦，請找資訊組協助。
Mac 多半已經內建。沒有的話，第一次用到時系統會自己跳出安裝提示，按同意就好。
學校筆電若鎖了安裝權限，會後要留版本時再找資訊組，或改用自己的筆電。不要因為這兩樣裝不起來就不來。

怎麼驗收：打開 Codex，貼這一句給它：

貼給 Codex
幫我確認這台電腦的 git 裝好了沒，跑一次 git --version 把結果給我
怎麼算裝好：它回你一串版本號（例如 git version 2.xx.x）就對了。

還要裝一個：GitHub CLI（讓 AI 能登入並操作 GitHub）

剛才那個 Git 負責記版本與傳送檔案；要讓 AI 登入 GitHub、建立 repo，再把整套流程接起來，還需要這個工具。

  1. 到 cli.github.com 下載安裝（Windows 一路 Next）
  2. 裝完要登入一次：在 Codex 裡貼下面這句
貼給 Codex
幫我跑 gh auth login，讓我登入 GitHub。
過程中如果要我去瀏覽器貼一組代碼，把那組代碼清楚地告訴我。
這一步會請你去瀏覽器貼一組八位數代碼，然後按「Authorize」。 那是 GitHub 在確認「真的是你本人」，AI 沒辦法幫你按——只有這一下要你自己來， 之後就都交給它了。
怎麼算裝好：在 Codex 貼「幫我跑 gh auth status」， 它回你「已登入」之類的訊息就成了。

最後一個（加分）：GitHub Desktop（有畫面的那個）

上面那個 Git 是給 AI 用的（它在背後跑指令）。 GitHub Desktop 是給你自己看的——有畫面、有按鈕，可以看到「我改了哪些檔案」「上次是什麼時候傳的」。

  1. 到 desktop.github.com 下載安裝
  2. 用第 06 項的 GitHub 帳號登入
它跟前面兩個的關係：Desktop 自己就能建 repo、提交、上傳， 不是非得配合前面那兩個才能用。
若要照留下版本 的提示詞讓 AI 自動留版本、上傳、下載並跨機器接手，就需要指令版的 Git 與已登入的 GitHub CLI。
Desktop 的價值在你自己看得見：它改了哪些檔案、上次什麼時候傳的，一眼就懂。
裝不起來也沒關係，這一項是加分不是必要——AI 用指令那個就能把事情做完。
部署是另一個選配步驟。要把網站公開時，可以選 GitHub Pages、Netlify 或其他服務；前面安裝 GitHub 工具的核心目的，是版本控制與跨機器接手，不綁定任何部署平台。

08 教材包與一個資料夾

上半場只要 Codex 開這個資料夾，它才叫得動 agy、也才找得到教材。下半場再另外用 Antigravity 桌面版開同一個位置。AI 代理就是能讀取整個專案資料夾、依步驟做事並回報結果的 AI，不只是回答一則聊天訊息。

  1. 教材有兩個來源，用一個就好：網站 github.com/cwstedctw/sci-club-toolkit → 綠色 Code → Download ZIP；或行前信／主辦發的教材包（官方原件在 OneDrive 活動夾的「官方文件」，不放進這個公開網站）。你已經在解壓後的教材裡看到這一頁，就略過下載。
  2. 先解壓縮，不要直接在 ZIP 裡操作。Windows 用右鍵「解壓縮全部」；Mac 雙擊 ZIP，Finder 會建立解壓縮後的資料夾。
  3. 在本機建立一個英文資料夾，例如 club2026。Windows 用檔案總管；Mac 用 Finder。若位置會自動同步到 OneDrive、iCloud Drive、Google 雲端硬碟或 Dropbox，請換到不會自動同步的位置。
  4. 把解壓縮後的教材內容複製進 club2026。Windows 用 Ctrl+A／Ctrl+C／Ctrl+V；Mac 用 Command+A／Command+C／Command+V。完成後，index.html、style.css、app.js 應直接出現在 club2026，不必再點進第二層。
  5. 在 club2026 新增 outputs 與 specs。作品放 outputs，每關確認過的規格放 specs，都不得覆蓋教材首頁。
  6. 把 templates 裡的學員檔複製到 club2026 根目錄：PROJECT-README.md、HANDOFF.md、LEARNER-RULES.md，以及兩份角色檔 領隊-洄瀾.md、隊員-秀姑巒.md。Codex 是洄瀾、agy 是秀姑巒。想換名字再改檔即可。

後面有些驗收或跨機器步驟會用到「完整路徑」。那不是資料夾的名字， 而是像 Windows 的 C:\Users\你的名字\Documents\club2026，或 Mac 的 /Users/你的帳號/Documents/club2026 這樣一整串。
Windows：打開檔案總管、進到資料夾，點上方網址列，再按 Ctrl+A、Ctrl+C。

這條路徑主要拿來核對兩個工具開的是同一個位置。真正開專案時，請使用工具裡的資料夾圖示或目前專案位置，選取整個資料夾；不要把資料夾拖進聊天視窗，避免它只被當成附件。

卡住怎麼辦

標準解法只有一句話：把畫面上的錯誤訊息，整段複製貼給你的 AI。

貼給 AI
我在裝軟體的時候卡住了，這是畫面上的錯誤訊息：

⟨在這裡整段貼上⟩

請用我聽得懂的話告訴我這是什麼意思，然後給我下一步該做什麼。
這不是「偷懶」，這就是這門課要教的能力本身。 遇到不會的技術問題、把錯誤訊息交給 AI 處理——這是這幾年最值得學會的一件事。

「可是我就是卡在裝 AI，哪來的 AI 可以問？」

兩種情況，各有解法：

  • 兩個都還沒裝好 → 用手機或電腦的瀏覽器，打開 chatgpt.com 的網頁版。網頁版不用安裝、免費就能用， 把錯誤訊息貼進去問一樣有效。
  • 裝好一個、另一個卡住 → 就問裝好的那個。 它答不出來也沒關係，至少會告訴你那行字在說什麼。

順帶一提，這一步本身就是在練習：把看不懂的東西丟給 AI， 是這門課從頭到尾都在教的事。你在行前先練一次，當天會順很多。

還是不行的話：

  • 當天提早 20 分鐘到，現場有人幫你看
  • 真的裝不起來，現場有做好的範例檔可以直接用，一樣做得完三樣東西
