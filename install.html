行前準備

8/19 之前，請先準備好這幾項

抓 40 分鐘就夠。全部免費，不用付一毛錢。 當天上午三小時要動手做三樣東西，時間很緊，所以裝軟體這件事請務必在家裡先做完。

裝不起來也請照樣來。 現場有做好的範例檔可以直接用，也有人可以幫你看。最怕的是因為裝不起來就不來——那才真的什麼都帶不走。
只有一件事現在就要記住：請用你的個人 Gmail，不要用學校配的帳號。 學校的 Google 帳號常常登不進 Antigravity，這是官方說明寫的，不是我們設定錯。

01 ChatGPT 帳號

要用它裡面的 Codex。免費方案就夠，不必升級付費。

  1. 到 chatgpt.com 註冊（有帳號就跳過）
  2. 用瀏覽器登入一次，確認進得去
怎麼算裝好：瀏覽器打得開 chatgpt.com，而且看得到自己的名字。

02 個人 Gmail（@gmail.com）

Antigravity 要用它登入。這是整份清單裡最常出問題的一項。

不要用學校配的 Google 帳號（那種 @xxx.edu.tw 的）。 官方說明寫得很清楚：機構帳號常常登不進去。沒有個人 Gmail 就先申請一個，免費、三分鐘。
  • 年齡要滿 18 歲並通過驗證，這是 Google 的規定
怎麼算裝好：你手上有一個 @gmail.com 結尾的帳號，而且記得密碼。

03 ChatGPT 桌面版 → 切到 Codex

這是「領隊」。負責想清楚要做什麼、以及回頭幫你檢查有沒有做錯。

  1. 到 chatgpt.com/download 下載安裝
  2. 用 01 的帳號登入
  3. 左上角的切換器切到 Codex（不是一般聊天模式）
別去搜尋「Codex」下載獨立軟體。 2026 年 7 月起它已經併進 ChatGPT app 裡了，網路上搜到的多半是過期教學，也有假冒的下載站。
好消息：介面是中文的。 下面那排「新聊天、Pull Request、網站、已排程、外掛程式」都看得懂， 不用怕整片英文。（Pull Request 那項我們用不到，不理它就好。）
怎麼算裝好：切到 Codex 之後，它可以「打開一個資料夾」。看得到這個功能就對了。
順便看一下你的額度。視窗左下角你的帳號旁邊會有一個百分比，那是目前用掉多少。 8/19 之前請讓它保持在低點——額度用完當天補不回來。

04 Antigravity 2.0（桌面版）

這是「隊員」。負責真的把檔案做出來。

  1. 只從 antigravity.google/download 下載
  2. 頁面上有四樣東西，請選 Antigravity 2.0（桌面版）。
    另外三樣寫著 IDE、CLI、SDK，那是給工程師用的版本，名字看起來很像但不是我們要的。按錯只是下載到用不到的軟體，不會弄壞電腦，刪掉重下就好。
  3. 用 02 的個人 Gmail 登入
有假冒的下載站會偷帳號。網址請自己打，不要點來路不明的連結。
Windows10 以上、64 位元
MacmacOS 12 以上，而且只支援 Apple Silicon（M1 之後的機型）。舊的 Intel Mac 不行 —— 這種情況請當天帶學校筆電或跟旁邊的老師併桌
裝好之後先別玩。它的免費額度是一週給一次，用完要等一週。 請把額度留給 8/19 那天動手的兩段。
怎麼算裝好：登入成功，而且開得起跟 Codex 同一個資料夾。

05 Antigravity 裝好之後，要調的設定

它出廠的安全等級最嚴，AI 每要做一個動作都會停下來問你。 先調好，當天才不會每三十秒被打斷一次。

設定在哪裡：視窗左下角的 Settings（齒輪圖示）， 或直接按 Ctrl + ,（逗號）。

點進去之後選左邊的 General，往下找 Agent Settings：

要改的第一個：Security Preset（安全等級）

Default
剛裝好就是這個		 官方寫：工作資料夾以外的檔案存取、以及所有終端機指令，都要人工審核。
→ 最安全，但它會一直問你，做起事來很慢。
Full machine
🌟 建議選這個		 官方寫：所有終端機指令仍然要審核，但 AI 可以讀寫這台電腦上的任何檔案。
→ 名字聽起來像「整台電腦交出去」，其實要動手時還是會問你，只是不必為了每個檔案再確認一次。
Turbo mode 官方寫：關閉所有安全屏障，換取最快的速度。
→ 不要選。你會不知道它對你的電腦做了什麼。
Custom 自己一項一項設。新手用不到。

要改的第二個：Artifact Review Policy（產出審核）

Always Ask
🌟 建議選這個		 它在提出「工作計畫」「修改對照」這類文件時，會先停下來讓你看過再繼續。
→ 多一個看得到它在想什麼的機會。
⚠️ 但這不等於「每個檔案寫進去之前都會問你」——它管的是那些給你看的說明文件， 不是所有的檔案動作。真正的把關還是你自己看成品。
Always Proceed 做完就繼續，不等你看。熟了之後再換。
一個小陷阱：下拉選單按 Esc 關不掉。 我們自己測的時候就是這樣誤選到別的選項。 要取消的話，把選單捲到原本那一項再點一次，或點選單以外的空白處，不要按 Esc 就走。
為什麼要管這個：8/19 有一段要示範「請 AI 幫你把檔案放上網路」。 那需要它跑電腦指令，設定太嚴會一直卡住、太鬆你又不知道它做了什麼。

上面的截圖與英文原文是 2026/8/12 在我們自己的 Windows 機器上拍的（Antigravity 桌面版）。 這兩個選項的完整說明，奕鈞老師整理得非常詳細，想看每個選單逐項對照可以看他的 Google Antigravity 系統設定全攻略。 如果你打開看到的跟這裡不一樣，以你畫面上的為準，並跟我們說一聲，這頁會更新。

06 GitHub 帳號

為了讓你做好的東西變成一個網址。校長要看、家長要看、明年接手的老師要看，傳一個連結就好，不用一直寄檔案。

  1. 到 github.com 註冊，免費
  2. 用 02 的個人 Gmail 註冊，跟 Antigravity 同一個比較好記
  3. 信箱會收到一封驗證信，點一下就完成
怎麼算裝好：瀏覽器登入 github.com，右上角看得到自己的頭像。

07 Git（＋ GitHub Desktop）

上一項是「網路上的地方」，這一項是「把東西送上去的工具」。你不用學它，交給 AI 用。

Windows 到 git-scm.com 下載，安裝時一路按 Next 就好，那些選項不用看懂。
其中一步請選 Install for me only —— 這樣就不需要管理員權限，學校的筆電也裝得起來。
Mac 多半已經內建。沒有的話，第一次用到時系統會自己跳出安裝提示，按同意就好。
學校配發的筆電如果鎖了安裝權限，先找資訊組開權限，或當天帶自己的筆電。
請務必試著裝——8/19 最後一段會用到。真的裝不起來，當天提早 20 分鐘到，我們現場幫你看；前面三段動手不受影響，不會整個下午白來。

怎麼驗收：打開 Codex，貼這一句給它：

幫我確認這台電腦的 git 裝好了沒，跑一次 git --version 把結果給我
怎麼算裝好：它回你一串版本號（例如 git version 2.xx.x）就對了。

還要裝一個：GitHub CLI（讓 AI 能自己開位置）

剛才那個 Git 只會「把檔案送上去」，它沒辦法在 GitHub 上開一個新位置。 要讓 AI 一句話從頭做到尾，還需要這個工具。

  1. 到 cli.github.com 下載安裝（Windows 一路 Next）
  2. 裝完要登入一次：在 Codex 裡貼下面這句
幫我跑 gh auth login，讓我登入 GitHub。
過程中如果要我去瀏覽器貼一組代碼，把那組代碼清楚地告訴我。
這一步會請你去瀏覽器貼一組八位數代碼，然後按「Authorize」。 那是 GitHub 在確認「真的是你本人」，AI 沒辦法幫你按——只有這一下要你自己來， 之後就都交給它了。
怎麼算裝好：在 Codex 貼「幫我跑 gh auth status」， 它回你「已登入」之類的訊息就成了。

最後一個（加分）：GitHub Desktop（有畫面的那個）

上面那個 Git 是給 AI 用的（它在背後跑指令）。 GitHub Desktop 是給你自己看的——有畫面、有按鈕，可以看到「我改了哪些檔案」「上次是什麼時候傳的」。

  1. 到 desktop.github.com 下載安裝
  2. 用第 06 項的 GitHub 帳號登入
它跟前面兩個的關係：Desktop 自己就能建 repo、提交、上傳， 不是非得配合前面那兩個才能用。
我們仍然請你裝前面兩個，是因為這門課要示範的是「AI 幫你做」， 而 AI 是在終端機下指令，需要指令版的 Git 與 GitHub CLI。
Desktop 的價值在你自己看得見：它改了哪些檔案、上次什麼時候傳的，一眼就懂。
裝不起來也沒關係，這一項是加分不是必要——AI 用指令那個就能把事情做完。

08 教材包與一個資料夾

兩個 AI 要看同一個資料夾，才有辦法接力。

  1. 下載行前信裡的教材包 ZIP，右鍵解壓縮（Windows 和 Mac 都內建，不用另外裝軟體）
  2. 在桌面開一個資料夾，名字用英文，例如 club2026
  3. 裡面先放兩份檔案：你的社團計畫書、基金會的成果報告書範本
  4. Codex 和 Antigravity 都打開這一個資料夾
資料夾和檔名都用英文或數字。中文檔名在後面幾關會出問題（網址會變成一串亂碼）。
另外別放在桌面的雲端同步資料夾裡（OneDrive、Google 雲端硬碟那種），同步會跟 AI 搶檔案。
怎麼算裝好：兩個 AI 印出來的資料夾路徑一模一樣。
「資料夾路徑」是什麼？怎麼複製給 AI？
後面每一關的提示詞都會叫你「貼上你的資料夾路徑」。那不是資料夾的名字， 而是像 C:\Users\你的名字\Desktop\club2026 這樣一整串。
怎麼拿到它：打開檔案總管、進到那個資料夾， 在上面那條網址列點一下（原本顯示「本機 > 桌面 > club2026」的地方）， 它會變成一整串文字，這時候按 Ctrl+A 全選、Ctrl+C 複製，就能貼給 AI 了。
更快的方法：直接把資料夾拖進 AI 的視窗裡，兩個工具都吃這一招，不用打任何字。

最後：花 3 分鐘自我檢查

在 Codex 貼這一句，它會告訴你有沒有真的讀到你的檔案：

請列出我這個資料夾裡所有檔案的檔名，一個一行。
然後告訴我我的計畫書第一頁的標題是什麼。
如果你打不開這個資料夾，直接說打不開，不要猜。
為什麼要問「第一頁的標題」？ 因為 AI 有時候會裝作讀過、其實是編的。標題只要有一個字對不上，它就是在編—— 這個檢查習慣，就是 8/19 那天要教你的主要東西之一。

卡住怎麼辦

標準解法只有一句話：把畫面上的錯誤訊息，整段複製貼給你的 AI。

我在裝軟體的時候卡住了，這是畫面上的錯誤訊息：

⟨在這裡整段貼上⟩

請用我聽得懂的話告訴我這是什麼意思，然後給我下一步該做什麼。
這不是「偷懶」，這就是這門課要教的能力本身。 遇到不會的技術問題、把錯誤訊息交給 AI 處理——這是這幾年最值得學會的一件事。

  • 當天提早 20 分鐘到，現場有人幫你看
  • 真的裝不起來，現場有做好的範例檔可以直接用，一樣做得完三樣東西
