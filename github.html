關 6

交出去：讓你做的東西有一個網址

這一關只講一件事：AI 可以幫你 commit、push；然後你在辦公室和家裡打開的，是同一份。沒有第二個概念。

名詞先講白話

GitHub：一個免費放檔案的地方，可以順便把檔案變成一個網址讓別人打開。
commit、push：就是「存一版」跟「傳上去」。這兩個字你不用會操作，AI 會做，你只要看得懂它在說什麼。
Pages：GitHub 把你的 HTML 檔變成真的網頁的功能。

1

這關做什麼

讓你的東西有一個網址，而且兩台電腦同步。

你前面幾關做出來的管理台、規劃表，現在只活在那台筆電裡。放上去之後：

  • 你會拿到一個網址，手機、平板、別人的電腦都打得開，對方不用登入、不用裝任何東西
  • 辦公室做一半，回家接著做，不用再寄檔案給自己
  • 改一行字，請 AI 更新上去，網址不變，內容變了
你現在就在看它

你現在看的這個教材網站，就是用這個方法放上網的。

行前要準備（併入行前信）

  • GitHub 帳號（免費，請用個人 gmail 註冊，不要用學校帳號）
  • Git，或 GitHub Desktop，二選一（要讓 AI 代操的話，裝 Git 就好）

8/19 現場示範腳本（10 分鐘，講師機投影）

時間做什麼你會看到什麼
0:00–0:30講一句：你做好的東西，現在只活在這台筆電裡問題被說中
0:30–3:00對 AI 說「幫我把這個資料夾放上 GitHub」AI 自己跑完，畫面吐出一個網址
3:00–5:00改一行字，對 AI 說「幫我更新上去」AI 自己 commit＋push
5:00–7:00拿手機開同一個網址網址沒變，內容已經更新
7:00–10:00收尾：辦公室做一半，回家接著做，不用再寄檔案給自己知道這件事為什麼值得裝
現場不講什麼（寫出來，避免失焦）

這一關只到「有網址、兩台同步」為止。想更深入的老師，教材頁末尾接「跟 AI 一起用 Git」工作坊（15 關，CC BY-NC-SA），自己走。

3

提示詞卡

前提：行前那三個工具要裝好

這一關要 AI 幫你做事，它需要三樣東西：Git（送檔案）、 GitHub CLI（在 GitHub 上開新位置）、還有你已經登入過一次的 GitHub 帳號。 三樣都在 行前安裝 那頁的第 06、07 項。
如果沒裝 GitHub CLI，AI 會卡在「找不到那個位置」 （repository not found）——因為單靠 Git 沒辦法憑空建出一個新的。

位置開好之後，下面這三句才用得上。第一句只用一次，之後每天用的其實只有第二、第三句。

① 第一次放上去
幫我把 ⟨貼上你的資料夾路徑⟩ 這個資料夾放上我的 GitHub，
建一個公開的 repo、開好 Pages，做完把網址給我。
動手前先列出你要上傳哪些檔案讓我確認，我說可以你再開始。
要什麼
一個可以打開的網址
AI 大概會回什麼
先列檔案清單等你確認，然後建 repo、上傳、開 Pages，最後給你網址
你要檢查什麼
清單裡有沒有出現任何人的資料；有就喊停。網址拿到後用手機開一次
如果 AI 開不了 Pages，你自己點也很快

到你的 repo 頁面 → Settings → 左邊選 Pages → Source 選 Deploy from a branch → 分支選 main（或 master）、資料夾選 / (root) → Save。
開好之後剛開會出現 404，官方說最多要等 10 分鐘，先去做別的事再回來看。

② 之後每次改完
幫我把剛剛的修改更新上去。
上傳前先列出這次要送上去的每一個檔案，還有每個檔案改了什麼，
讓我確認過再動手。不要用「全部一起加」的方式。
要什麼
網址上的內容跟著你的修改變新
AI 大概會回什麼
它會 commit＋push，然後回報完成
你要檢查什麼
重新整理那個網址，改的那行字有變嗎（要等，有時候要幾分鐘才會換過去）
③ 換另一台電腦時
我在另一台電腦，幫我把 GitHub 上那份最新的抓下來。
如果這台電腦上已經有我改到一半的東西，先告訴我，不要直接蓋掉。
要什麼
這台電腦拿到最新的那一份
AI 大概會回什麼
它會把檔案下載更新到你指定的資料夾
你要檢查什麼
打開檔案，看看是不是你在另一台改的那一版
④ 出錯的時候
出錯了，這是錯誤訊息：⟨整段貼上⟩
要什麼
把問題交回給 AI 處理
AI 大概會回什麼
它會解釋原因並直接處理
你要檢查什麼
錯誤訊息整段貼上，不要只貼最後一行、也不要自己重打
4

新手會卡在哪

  • 第一次 push 要登入授權，瀏覽器會自己跳出來 → 正常，照著按就好。
  • repo 設成 Private → 用免費方案時 Pages 開不了，要設成 Public。（付費方案可以用私人 repo 開 Pages，但我們用不到。）
  • 首頁檔名不是 index.html → 開出來多半是「404 找不到頁面」。首頁一定要叫 index.html。
  • Pages 剛開會先出現 404 → 正常，要等。官方說最多可能要 10 分鐘，別急著砍掉重做。
  • 中文檔名在網址會變成一長串亂碼（不一定開不了，但很難傳給別人） → 檔名一律英文，頁面才開得起來。
🚨 放上去就是公開的

管理台裡如果有真實學生名單，另外開一個乾淨的資料夾，只把「要給別人看的檔案」複製過去再上傳。不要拿原本那個工作資料夾按「載入練習用範例」就當作清乾淨了——真名可能還留在瀏覽器的暫存、你匯出過的備份檔、或資料夾裡你忘記的檔案。網址一旦公開，任何人都打得開，事後刪掉也可能已經被存下來。

會外傳的東西一律只放虛構名單。真名單留在你自己的電腦或學校雲端。

上傳前一定要先問 AI 這一句（不要跳過）：

先不要上傳。請先做兩件事：
一、列出你打算上傳的每一個檔案（含隱藏檔），一個一行。
二、逐檔告訴我裡面有沒有出現這些東西：姓名、學號、班級座號、
    電話、email、地址、生日、照片裡的人臉、家長資料。
我確認之後你再上傳。

它列完你自己看一遍，有真名就停下來。東西一旦推上去，就算你之後刪掉，紀錄裡還是留得住
