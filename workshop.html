行前必做（請在 8/19 之前完成）

還沒好的話，當天會來不及
  1. 照行前安裝解壓教材包，把內容複製進 club2026，並照頁面建立 sources、specs、outputs 與三份學員記憶檔。
  2. 把五類原件放進 sources：官方成果報告書範本、基金會共識營簡報、去識別化校內計畫、校務行事曆、校內核銷空白表。缺哪一份，就依來源清單標成待補，不要讓 AI 猜。
  3. 完成關 0；Codex 與 Antigravity 都要開啟同一個 club2026，並在教室的網路試過一次。
  4. 註冊並驗證 GitHub 帳號，安裝 Git 與 GitHub CLI，完成 GitHub CLI 登入；GitHub Desktop 選配（關 6）。這組工具要讓 AI 自動留版本、上傳、下載並跨機器接手，請不要把安裝與登入留到現場
  5. 額度先別玩：Codex 與 Antigravity 的額度都留給當天實作

裝不起來不用急。當天講師手上有做好的範例檔，卡住的人直接用那份往下做，不排隊等修電腦。

11:40–11:50關 6 示範：先看版本差異並 commit／push，再用另一台電腦或第二個空資料夾 clone，讓另一個 AI 讀專案記憶後接手看懂版本控制與跨機器接續
11:50–12:00收下半場作品、確認檔名與問題紀錄完成第二次收件；有未完成處就記成「待確認」帶回去接著做

教材網目前採用的收件節點為 10:22 與 11:50。關 6 會示範 AI 用 commit／push 留下版本，再從另一台電腦用 clone／pull 接續；跟著 repo 走的是 PROJECT-README、HANDOFF、LEARNER-RULES、specs 與逐檔核准的去識別化作品，不含 sources 原件或教材改善工單。部署是獨立選配，可使用 GitHub Pages、Netlify 或其他服務。

從 200 張挑 12 張

官方報告書的「課程紀錄」只要求一段文字說明配 6 張照片，兩項共 12 張，沒有要求每張都寫圖說。所以難的不是寫 200 句，是挑。

挑照片的三個問題（可以印成小卡）：

  1. 這張對應到第幾週？答不出來就不選。
  2. 這一週已經有兩張了嗎？（一張看得到人在動作、一張是東西或成果）
  3. 今天有沒有失敗或意外？有的話優先放——官方計畫目的就寫著「從失敗中找原因」。

現場會出什麼問題、怎麼救

會發生什麼為什麼怎麼救
AI 說「完成了」但找不到檔案它存到自己的暫存資料夾去了先講：等一下它會告訴你檔案在哪，那行字很重要
AI 寫的內容根本不是我的計畫它沒讀到你的檔案，就自己編一個驗收口訣：先對路徑、再對數量、再抽查內容
免費額度用完了Antigravity 免費額度按週刷新，當天無法立刻補回課前就講：只做最低限度讀檔檢查，把額度留到當天
學校筆電登不進去校園網路可能會擋課前請在教室網路試一次
有人裝不起來各校電腦權限不同講師手上有做好的範例檔，卡住的人直接用

現場分工：文盛在台上示範，豐兆和工讀在台下走動。發現兩個人以上出現同一個問題，就全班暫停統一處理，不要一台一台救。

一個投稿機會

2027 第十三屆「北花蓮」全民科學週教案徵選，9/20（日）截止，國小組 6 名、國中高中組 6 名；入選可三擇一——獎金 2,000 元／縣府敘獎／縣府獎狀。

要投的是另外一份東西：官方 C03 表格的單一實驗教案（2 節課，另含 10 分鐘闖關版），要寫到活動原理、材料、步驟、評量檢測、預算表。今天做的四樣是報告書的地基，不是這一份。

但有個好消息：C03 的「教案來源」三選一裡就有一格「AI 協作」，官方明文接受，只要求附上協作舉證——你今天學的三段提示詞加驗收口訣，就是那份舉證。
