# 關卡原件放置說明

這個資料夾只放學員自己取得、已確認可使用的工作原件。教材 repo **沒有附上**基金會或各校的原始 Word、PDF、Excel；不要從別人的電腦複製，也不要把未獲授權的原件提交到 GitHub。

請保留原本副檔名，並把檔名開頭改成下表的固定代號。AI 會依代號找檔，不會猜哪一份才是最新版。

| 固定檔名開頭 | 需要的資料 | 取得來源 | 缺少時怎麼做 |
|---|---|---|---|
| `01-official-result-template.*` | 基金會當學年度成果報告書官方範本，含附件一、二、三 | 行前信、主辦單位提供的共用資料夾，或基金會確認的來源 | 課程規劃表、名單與出席、學生回饋單、結案 只能用虛構資料練習；不得宣稱符合正式欄位 |
| `02-foundation-consensus-slides.*` | 基金會共識營的經費與核銷簡報 | 行前信、共識營資料，或主辦單位確認的來源 | 核銷對帳 只能練習；不得把金額或核銷判斷當成正式結論 |
| `03-school-plan-deidentified.*` | 本校核定社團計畫的去識別化副本 | 本校承辦人 | 課程規劃表 不能產生本校正式課程表，只能做虛構範例 |
| `04-school-calendar.*` | 本校行事曆 | 本校公告或承辦人 | 日期全部標「待人工核對」，仍可練習其他功能 |
| `05-school-reimbursement-blank.*` | 本校目前使用的核銷空白表 | 本校主計室或承辦人 | 核銷對帳 只能做基金會規則練習，不能判定本校該用哪張表 |

`*` 代表保留原副檔名，例如 `.docx`、`.pdf` 或 `.xlsx`。同一代號若有兩份以上，先移走舊版；不要叫 AI 自己挑。

## 個資與版本

- `03-school-plan-deidentified.*` 必須先移除學生姓名、私人電話、地址與其他不必要個資。
- `05-school-reimbursement-blank.*` 只放空白表，不放已填寫的印領清冊、匯款帳號或身分證字號。
- 原件只留在本機 `club2026/sources/`。建立 `club2026-share` 時，整個 `sources/` 都不要複製。
- 正式送件前，仍要向基金會窗口、本校承辦人與主計室確認版本、公式與送件方式。
